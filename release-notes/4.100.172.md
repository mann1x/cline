## A fan-out of identical agents is not a loop; collapse a sub-agent's prompt

- **Identical calls in one message are no longer treated as a loop.** Asked
  for 15 agents of each of five types, qwen sent all 75 calls in one message:
  15 identical calls per type, as asked. The repeated-call guard counted them
  as 15 consecutive attempts at the same call. It warned at the fifth, stopped
  the run at the sixth, and every call in the message failed with "Detected 6
  consecutive identical calls". No result had come back between any of them,
  so there was nothing the model could have failed to learn from. Identical
  calls in one message now count once. The same call repeated in a later
  message still counts as a repeat.
- **"Show less" on a sub-agent row.** "Show more" opened a long sub-agent
  prompt in the chat, and nothing closed it again. An expanded prompt now has
  a "Show less" link that clamps it back to two lines.
