## Prompt templates

- **`restore_file` and `task_progress` have a section in every built-in
  template.** Both tools reached the model with their built-in description,
  whichever template was in use, because the runtime adds them outside the
  tool list the templates were checked against. automaticum found it by
  comparing the tools a session offers with the template's sections (13 tools
  offered, 11 with a section). Each built-in template now has a section for
  both: `default.md` with the description itself, the family templates with
  `{{DEFAULT}}`, as for most of their tools. A test now builds the tools from
  the same functions a session's tools come from, with every option on, and
  fails when any of them has no section in a template. Mutation-checked: with
  the two tools taken out of the test's list it fails, naming `task_progress`.
- **The `sed` description no longer uses line 90 as its example.** The note
  added in 4.100.286, that `90p` without `quiet` prints the whole file with
  line 90 twice, named the line the manic_miner benchmark breaks. A test
  exists to keep benchmark details out of what the model reads, and it was
  failing on the three templates that carried the sentence. The example is now
  line 12. The note shown after a real run still names the actual lines.
