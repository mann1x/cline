## Restart a stuck agent, see what agents spend, and get a recommended option

- **Restart an agent without losing it.** An agent's panel now has a
  **Restart** button next to Stop. It abandons what the agent is doing and
  starts it again from its task, in the same place in the round. The lead
  gets the new attempt's report, not "stopped". It works for an agent stuck
  after a server restart, or one looping in its output. It gives back the
  abandoned attempt's server session first, and works while the agent is
  queued too. It covers `spawn_agent`, configured agents and swarms.
- **Agent rows show the tokens they use.** Nothing reported usage while an
  agent ran, so every row read "0 tokens", and still did after it finished.
  Rows now update every turn with the context the agent holds, and a
  finished row shows what it spent.
- **Questions mark the option the model would pick.** Across 566 sessions,
  0 of 19 questions carried a "(recommended)" option. The instruction was
  opt-in and hedged three ways, and the qwen and gemma templates restated
  the tool without it. Marking is now the default, with one exception: when
  the choice depends on your taste or something only you know. The
  instruction is also in the tool's `options` field.
