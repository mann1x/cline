## SDK

- **A session reports what it was built with.** `onConfigResolved` on the
  session configuration is called before the first request with the context
  window, the output cap, thinking, the sampler, the provider and session
  settings (secrets removed) and the system prompt as it will be sent. It also
  lists which provider fields came from a profile stored on disk and not from
  the caller. Throwing from it stops the session from starting. The result of
  starting a session carries the same report.
- **A session can ignore the stored provider profile.**
  `storedProviderSettings: "ignore"` builds it from the configuration passed
  in and nothing else, so one run cannot inherit a sampler, a window or a base
  URL from another.
- **`contextWindow` on the session configuration** sets the lead's window,
  including the `num_ctx` sent to a server that takes one.
- **`dataDir` on `ClineCore.create`** puts everything the process stores under
  one directory.

These are for programs that drive Cerebriline through `@cerebriline/sdk`, such
as a test harness. Nothing changes in the extension or the CLI.
