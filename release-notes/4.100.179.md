## Agents share their prefix again, ask the lead instead of you, and show what they are doing

- **Every agent's pool matches its requests again.** A request sent with
  thinking off (`reasoning_budget_tokens: 0`) renders Gemma-4's system turn
  without `<|think|>`, but pools were rendered without the request's
  settings. So every worker's request diverged from its pool at token 4,
  and each turn prefilled its whole ~5.6k-token prompt again. Swarm pools
  and the lead's pool tree are now rendered with the request's own
  settings, and keyed by them. On 8240 a probe went from 4 of 21 tokens
  shared to 19 of 19.
- **A pool that shares less than it should is reported.** Workers' responses
  were never read for the engine's `pool_match` / `pool_len`, so the
  divergence showed up only in the server log. It now appears on the agent.
- **An agent's question goes to the lead, not to you.** A delegated agent's
  `ask_question` reached you directly, and the whole round, lead included,
  waited 19 minutes for the answer. The question now ends the agent's run
  and becomes its report. The lead decides whether to answer it, run the
  agent again, or ask you.
- **Delegated agents get `check_file`, `ask_lsp` and `list_files`.** They had
  only the core tools, so `check_file`, which their instructions name, was
  "unavailable". The terminal and the browser are still not shared.
- **The agent panel shows what the agent has been doing.** Opening an agent
  shows its recent activity: placement, tool calls, waits and refusals, and
  engine warnings. Warnings have a ⚠ and are orange, and an agent with a
  warning carries the ⚠ on its tag too.
