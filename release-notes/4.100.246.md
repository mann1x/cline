## Code search by meaning: agents and the CLI

- **Agents** the lead starts are now offered `search_codebase`'s `semantic`
  mode in a folder that is indexed. The index is the lead's; the lines of a
  passage are given as they are in the agent's own copy of the folder.
- **CLI**: `--code-index` (or `CLINE_CODE_INDEX=1`) turns the mode on for the
  folder the run is in. It needs `CLINE_EMBEDDING_BASE_URL` and
  `CLINE_EMBEDDING_MODEL`, and downloads LanceDB into the data folder the first
  time.

## xOllama: no more five-minute pauses after a long think

- On xOllama a run could go silent for about five minutes after a turn whose
  thinking hit its budget. The note written about that thinking is a request
  of its own, and it was refused for space the conversation itself was
  holding while idle; it only got through when the engine's five-minute idle
  timer released the conversation.
- The note now asks for exactly the space it needs and gets an answer at
  once. If the only thing in its way is its own conversation's idle window,
  that window is released straight away and the note runs. The conversation's
  next turn re-reads its prompt once, as it already did after the pause.
- In every other case nothing is released: the note waits as before, and the
  log says what it is waiting for.
