## Council compaction prompts you can edit, and templates that can carry them

- **The council's three prompts are in Features.** Under Compaction Council
  there are now three fields, each with a load-default and a reset button:
  - the **writer instruction**, which marks where the replay is cut in two;
  - the **reviewer prompt**, which each of the two reviewers gets;
  - the **synthesizer prompt**, which the pass that joins the halves gets.

  An empty field uses the built-in prompt. A custom prompt changes only the
  instructions. The harness still appends what the council depends on (the
  halves, the call record, the transcript and the answer format), so a custom
  prompt cannot break the format the council reads back.
- **The halfway marker is asked for only when the council runs.** The "mark
  the halfway point" section used to be part of the replay prompt, even with
  the council off. It is now its own instruction, added only while the council
  is on. It now reaches full compaction too, which never asked for it before,
  so the council had to guess the cut.
- **A prompt template can carry compaction prompts.** A
  `# compaction: <id>` section in a template replaces that prompt for the
  models the template claims. The ids are `replay`, `full`, `retrospective`,
  `council-writer`, `council-critic` and `council-synthesizer`. The template
  section wins over the Features field, which wins over the built-in. The
  session log names any compaction prompt a template supplies.
- **Generate can translate them, if you ask.** A new **Translate Compaction
  Prompts** switch sits under the template generator, off by default. When it
  is on, Generate also asks the model to rewrite all six compaction prompts,
  starting from your own Features prompts where you set them. Each rewrite is
  checked: every placeholder and marker kept, and no shrinking below half the
  source. A section that still fails after the repair rounds is removed from
  the file, so that prompt uses the built-in. The notice after Generate names
  the compaction sections the file kept and the ones it cut. Review them
  before relying on the template, and delete a section to go back.
- **The review script has `--compaction` and `--compaction-id <id>`**, for
  trying the same translation on the built-in templates. No shipped template
  carries a compaction section yet.
