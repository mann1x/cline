## A swarm can run your configured agents

- **`type` works with `merge: true`.** In a swarm, an `agents` entry naming a
  configured agent now runs with that agent's own role and tool list, on the
  swarm's nodes and shared snapshot. Before, the swarm dropped `type`, so "15
  code-verifiers as a swarm" ran 15 generic workers. With `count`, "15 of each
  of five agents, merged" is one call with five entries.
- **An agent pinned to its own model is refused in a swarm, by name.** Swarm
  workers all run on the swarm's shared snapshot, so an agent whose file names
  its own provider, model or profile can't join one without changing its
  model. The error says so and tells the model to send those entries without
  `merge`, where each runs on its own model with its own report. An unknown
  `type` is refused with the list of configured agents.
