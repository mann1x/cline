## Swarm agents you can see, stop, and that fit on the engine

- **A merged swarm (`spawn_agent` with `merge: true`) now shows its agents.**
  Each worker gets its own row and a tag in the working-agents strip. The row
  shows whether it is queued or running, which node it is on, its tool calls
  and output, and how it ended. Before, a swarm sent no progress at all: every
  row read "0 tools called · 0 tokens" for the whole round, the strip never
  appeared, and the lead looked stuck on "generating".
- **A failed agent says why.** A swarm worker that fails, is refused by the
  engine until it gives up, is stopped, or never gets a turn now shows as
  failed with the reason on its row. While a node refuses it, the row shows the
  engine's refusal and the retry count.
- **Stop all.** The working-agents strip has a **Stop all** button beside the
  count of running and queued agents. It asks for confirmation first, then
  stops every agent that can be stopped. Queued swarm workers are stopped
  before they start.
- **Swarm workers fit on a PolyKV engine.** A worker placed on an opencoti
  node the lead is not on now joins that node's pool tree, the way
  `spawn_agent` agents do, instead of booking a full session window each.
  Measured on a 1M-cell server: 262,144 cells per worker, 4 running, the 5th
  refused 74 times.
- **Swarm workers compact in their own name.** Their compaction ran under the
  lead's session id. On a node the lead is not on, that pinned an unowned
  prefix pool that was never released, and each worker's first turn read the
  lead's context size.
- **A refused node steps aside.** A capped node that refuses an agent now takes
  no new agent until one of its own finishes or 5 s pass. The agent goes to
  another node with room. Before, the refused agent went straight back to the
  same node because its slot count said there was room. Uncapped nodes already
  worked this way.
- **Swarm workers cannot ask you questions.** A worker's transcript is thrown
  away, and a question from one stalled the round behind a prompt with no
  context.
