## Stop one agent without stopping the session

A runaway sub-agent had one control: cancel the task. That is the wrong one —
a fan-out of five where a single agent grinds has four reports already written,
and cancelling the session throws them away along with the lead's context.

Each agent now runs on an abort signal of its own, linked to the session's so a
task cancel still reaches everything, and the strip above the conversation
carries a stop beside each one. The button appears the moment the agent is
registered rather than with its first tool call — an agent that never gets as
far as a tool call is exactly the one worth stopping.

An abort is a request, not an event: the run may be inside a model call that
has to return first. So the row stays and the button disables while the stop is
in flight, instead of looking like it did nothing and inviting a second press.
A stop for an agent that has already finished does nothing, which is the good
outcome rather than an error.

## A price of nothing is not worth a column

    1 tools called · 0 tokens · $0.00

That was on every sub-agent row of every run, and on a local endpoint it is
always that. The price is shown when there is one, including below a cent where
it keeps four decimal places — a paid run reading as free is the thing this must
not start doing.
