## A finished agent's row says it finished

- **Each agent in a batch or swarm finishes on its own row.** A `spawn_agent`
  batch or a swarm closed all of its rows only when the whole call ended. So
  an agent that was done sat on a "running" row, showing its output, until
  the slowest agent in the round finished. On a swarm this showed 16 rows
  running while the server processed one. Each agent now reports when it
  ends, and its row turns completed, or failed with the reason, right away.
