## Images

- **`render_image`: the model draws screens and diagrams by writing them.**
  Asked for "rendered images showing the workflow of the application", a model
  used the image generator and got dashboards with garbled labels. An image
  model cannot write a word. The new tool takes HTML and CSS, SVG or a Mermaid
  diagram that the model writes and renders it in a headless Chrome, so every
  label is the text that was typed. The picture is exactly as large as what was
  drawn unless a size is asked for; `width`, `height`, `scale` and `crop` set
  it. Relative links resolve from the workspace, so a screen can use the
  project's own stylesheet. A diagram can be saved as `.svg`. It needs no image
  endpoint and no model, and answers to the browser's approval box.
- **`transform_image`: resize, crop and convert.** One side or both (with
  `inside`, `cover`, `pad` or `stretch`), a crop in pixels, and the format from
  the file name: `.png`, `.jpg`, `.webp`, `.ico`, `.icns`. The source is never
  changed. No shell command and no installed program is needed.
- **`generate_icon`: proposals to choose from, then every icon file.** With a
  prompt it draws several candidates and shows them on one numbered sheet; the
  model asks you which one. With the chosen one it writes `.ico`, `.icns`, a
  1024 pixel PNG and the PNG sizes a page and a phone ask for. An image you
  already have can be turned into an icon the same way. Offered when an image
  endpoint is set on the Images tab.
- **`generate_image` no longer offers itself for mockups**, and says to write
  anything with words in it as HTML, SVG or Mermaid instead.

## Skills

- **Three built-in skills for media, turned on by default:** `media-images`,
  `media-audio` and `media-video`. A model had to be told that it could
  generate images at all. The skills say which tool fits which job, how to make
  a picture of a screen from the application's own markup, when a README wants
  a Mermaid block and when a rendered file, and where each tool is switched on
  when it is missing. Turn one off in the Skills tab.

## Agents

- **The agent's live output no longer blanks between steps.** When an agent
  started a new step, the Inspect view was cleared at once and showed "Nothing
  generated yet" until the model answered. The previous step now stays on
  screen until the new one produces its first text.
