## Jev: a confidence score before acting

- **Use Jev for confidence.** A new box under *Use an endpoint for image
  generation* turns on Jev, TypeSafe's scoring model, and adds a **Jev** tab
  for the API key, model, confidence floors and timeout. Jev answers typed
  questions with a probability and a confidence. Nothing is sent until the
  box is ticked and a key is stored.
- **A `jev` tool.** The model calls it when it is unsure it understood your
  request, whether a fact is supported, or which approach to take, and it
  acts only on answers that clear your floor. A short rule in the system
  prompt says when to call it, and it is there only when the tool is.
- **Questions come with scores.** Before a question from the model reaches
  you, Jev ranks its options against what you have said:
  - the likeliest option is marked recommended when Jev is confident;
  - each option shows its score;
  - options under 5% are left out, keeping at least two.

  You can still type any answer. Escalation approvals are never touched.
- **Escalations carry a complexity score.** When the model escalates, Jev's
  complexity score and its read on whether the run is stuck go into the
  assessment you approve from and the expert reads.
- **Fixed: unticking image generation now removes `generate_image`.** Before,
  a stored endpoint kept the tool offered with the box unticked.
