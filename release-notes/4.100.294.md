## Find a skill or a profile in a long list, and rename a profile in place

- **The Skills tab has a filter** ([#116](https://github.com/mann1x/cline/issues/116)).
  Type part of a skill's name or description and every group shows only the
  skills that match, every word in any order and any case. A collapsed group
  with a match opens by itself, a group with none drops out, the group
  heading says how many of its skills match, and Escape or the clear button
  brings the full list back.
- **The API configuration profile picker filters as you type.** It is a text
  field now instead of a dropdown: it shows the loaded profile, and clicking
  it opens the full list with that name selected, so typing replaces it and
  narrows the list. The arrows move through it, Enter loads the highlighted
  profile (or the only one left), and the loaded profile has a check mark.
  Picking a profile over unsaved changes still asks first, as before.
- **Rename a profile from its right-click menu.** Right-click the picker, or
  any profile in its open list, for **Rename…**, **Copy name** and
  **Delete…**; the context-menu key and Shift+F10 open the same menu.
  Renaming used to take "Save as…" under the new name and a Delete of the old
  one. Every tab that has the profile loaded keeps it loaded under the new
  name, and so do the Memory panel's query expansion and the Library's image
  profile when they use it. A name another profile already has is refused.
  Agents name a profile in their own files, which a rename does not edit; the
  rename row lists any agent that names the old profile so it can be updated
  on the Agents tab.
