## Conversations on one opencoti server now share across windows, and book less

This release is for the opencoti build `2609230917001` (patch 0352), which
fixed the engine issues found while building the shared prefix for 4.100.164.
Each fix is detected from the server's feature list, so an older server gets
exactly the 4.100.164 behaviour.

- **One shared root across windows.** Two VS Code windows, or the CLI, attached
  to the same server now find the same shared root instead of each making one.
  The engine ends it once nothing uses it; no window has to guess when the
  others are done, and a crash leaves nothing behind.
- **The window is booked without the shared part.** A new conversation books
  its context window minus what it shares, and still sees the whole window.
  Measured: 32,768 asked, 31,252 booked. Across N conversations that is
  N × (W − P) + P instead of N × W, so more conversations fit on the same
  server.
- **A prefix that does not match is reported.** When a pool matches less of the
  request than its own length, the extension log says so, with both numbers.

Measured on the 8240 server with the new build:
- 50 agents × 2 turns: every turn shared its prefix, and the owner window
  peaked at 7,095 cells, where it was 163,787 before.
- Every turn of every conversation now shares the root. Before, only the first
  turn of the first conversation did.
