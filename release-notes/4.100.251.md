## SDK

- **The npm packages now carry the fork's own fixes to two libraries.** The
  SDK changes the Ollama library and the EPUB library it uses, and those
  changes lived only in this repository. An installed `@cerebriline/sdk` got
  the unchanged libraries from npm instead. Both are now built into the
  packages. What that fixes for anyone using the SDK from npm:
  - **Thinking effort on Ollama and xOllama.** Every level was sent as a plain
    "think", so the server used the model's own budget whatever was asked.
    `high` is now sent as `high`.
  - **Sampler settings the Ollama library does not know**, such as a presence
    penalty of 0 or a thinking budget, were dropped from the request. They are
    sent.
  - **EPUB files whose package files use namespace prefixes** could not be
    read.
- **A fresh install works.** The packages asked for any zod 4 from 4.3.6 up,
  npm chose a newer one than the SDK was built with, and the first session
  with tools failed with "Cannot read properties of undefined (reading
  'push')". The packages now name the exact zod version they were built with.
- The release's own install test now runs a session against a stand-in server
  and reads the request, so a package that loads but sends the wrong thing is
  caught before it is published.

The extension and the CLI were never affected: they are built inside the
repository, with the changed libraries.
