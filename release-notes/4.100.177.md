## A waiting agent says it is waiting, and a finished swarm gives its memory back

- **An agent waiting for room on the server is shown as queued.** A swarm
  agent whose window on the server was full waited inside the request, and
  its row went on saying "running". 75 rows showed running while the server
  was processing 27. The row now switches to queued, with "Waiting for room on
  the server" as its last line, and back to running when its request goes out.
  This covers `spawn_agent`, configured agents and swarms.
- **Swarm agents are closed when they finish.** `spawn_agent` and configured
  agents gave their session back on the server when they ended; swarm workers
  did not. So a swarm's windows stayed booked until the server's 5-minute idle
  timeout. KV headroom stuck at 75% after a run was one of those windows. Each
  worker now closes its session as it ends, and the last one on a window
  closes the window. A worker moved to another node is released first.
