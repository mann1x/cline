## Fixes

- **The model list fills in when a server that was down comes back.** On an
  opencoti, llama.cpp or other OpenAI-compatible provider whose server was
  not running when Settings opened, Model ID stayed a plain text field after
  the server came up, even with the status dot green; switching to another
  tab and back was the only way to get the model dropdown. The list is now
  asked for again when the status dot answers ready (pressing the dot fills
  it at once), and every 15 seconds while it is empty and the panel is
  visible; when that finds the server back, the dot turns green by itself.
